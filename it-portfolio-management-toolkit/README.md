# IT Portfolio Management Toolkit

A practical demonstration of portfolio oversight: delivery health, priorities, risks, dependencies, KPIs, and executive reporting.

## Included
- `dashboard/index.html`: standalone interactive dashboard; open it in a browser.
- `data/projects.json`: fictional sample portfolio.
- `templates/RAID-log.csv`: risks, assumptions, issues, and dependencies.
- `templates/project-status-report.md`: executive status report template.
- `docs/portfolio-governance.md`: suggested governance cadence and controls.

All data is fictional and illustrative.
